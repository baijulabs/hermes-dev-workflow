⬡ Dev Workflow Pipeline v2.0

Happy path: GH issue → staging deploy. Phased naming: {phase}-{action}
👑 HAPPY PATH — Core CI/Deploy
ingest-gh-issues
every 5m
sync
1. Issue Ingestion
Syncs GH issues labeled ready-for-agent → creates orchestrator kanban card. Ingestion only — never closes issues.
trigger: label `ready-for-agent` output: orchestrator card (todo)
⤷ auto-decompose: orchestrator splits issue → coder + reviewer cards with branch guardrails
queue-agent-processor
every 30m · 7-21
dispatch
2. Agent Dispatch
Claims ready cards → dispatches coder (implements fix in worktree) + reviewer (approves)
coder writes fix, pushes worktree reviewer approves → both cards done
⤷ both cards marked done, branch has unique commits vs main
build-consolidate-prs
every 5m
build
3. PR Consolidation
Finds done coder+reviewer pairs by GH issue → merges worktrees → creates consolidation PR with Closes #N
creates `fix/consolidate-gh-N` 0-commits check → auto-archive dedup by commit hash
⤷ edge case handlers (every 5m): build-reviewer-resolve · build-reviewer-approve · build-coder-resolve
⤷ PR created → CI triggers (test jobs only — deploy does NOT run on PR creation)
merge-ready-prs
every 10m
merge
4. PR Merge
Merges PRs where BOTH: mergeable=MERGEABLE AND mergeStateStatus=clean (all CI green). Uses --merge (preserves commit hashes). Single version bump per tick.
requires CI: clean (no pending, no failing) gh pr merge --merge --delete-branch deploy cooldown gate
⤷ PR merged to main → deploy.yml triggers on pull_request_target closed + merged
ingest-deploy-failures
every 15m
detect
5. Deploy Failure Detection
Checks latest main deploy runs at job level (Deploy to Staging job conclusion, not workflow). Creates fix cards on failure.
checks Deploy to Staging job conclusion dedup via kanban in-flight cards
⤷ deploy succeeds → staging updated
verify-deploy-qa
every 10m
verify
6. Post-Deploy QA
Validates staging health (healthz, critical flows), maps changed files → affected E2E steps. Creates GH issues for bugs found.
health check + critical flows creates GH issues for found bugs
⟳ PARALLEL DETECTION — CI Failures on Open PRs
ingest-ci-failures
every 5m
detect
CI Failure & Conflict Detection
Monitors open PRs for failing CI checks or MERGEABLE=CONFLICTING. Enqueues fix tasks → agent creates coder+reviewer cards. For conflicts: fix pushed directly to existing PR branch (no new PR created).
re-triggers CI when PR HEAD changes conflicts → fix on existing PR branch dedup via agent queue
